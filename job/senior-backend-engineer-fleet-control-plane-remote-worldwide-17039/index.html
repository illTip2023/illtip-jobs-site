Senior Backend Engineer, Fleet Control Plane (Remote - Worldwide)

Remote - WorldwideFull-time$143,800–$231,900 per yearPosted Yesterday

Pay ranges are published by region; the figures shown are the US range (total target cash, base plus variable). Other regions are hired through a global employment partner with location-based pay. A fast-growing enterprise software company that sells workflow and process orchestration to large banks and other big organisations is hiring a senior backend engineer for a new two-person pod. The role owns the backend and architecture of a central management product that controls many customer-run clusters, covering access, secrets, tenants, licences and deployment visibility. The team is fully remote and is moving to an AI-first way of working, with written specifications taken through to production.

What you'll do

  • Take over an existing mechanism that pushes configuration changes out to every connected cluster and extend it to access, secrets, tenants, licences and custom roles
  • Write short design documents for foundational changes, gather review from dependent teams, and deliver tested, shipped code
  • Design behaviour for failure cases such as offline clusters, partial failures, central service outages, and clusters being adopted or detached
  • Build the return path from clusters to the central service for deployment inventory, health, audit records and licence status
  • Design the first event and webhook mechanism so administrators and automated agents can react to changes
  • Join on-call and pod rotations, and support other engineers through code reviews, guidelines and contract tests

What you need

  • Designed and shipped a control plane or similar system that pushes desired state to many targets, with working knowledge of outbox or event-log patterns, idempotent apply, versioning, retries and drift reconciliation
  • Senior backend experience in Java, including API design, relational data models and multi-tenant SaaS services
  • Hands-on experience with Helm and Kubernetes for self-managed installations
  • Solid grasp of distributed-system failure analysis, including partial failure, blast radius and consistency trade-offs, and experience debugging production incidents
  • Experience shaping an API or platform for technical users and writing design documents that other teams can build on
  • Comfortable working asynchronously in English with a remote team and checking AI-generated output as carefully as any other code

Open to applicants anywhere in the world.
