DevSecOps Engineer - AWS (Remote - US only)

Remote - US onlyFull-timePosted 2 days ago

Candidates must be located in the Eastern or Central Time Zone and be authorized to work in the United States without sponsorship. A privately held information security firm that provides advisory, solutions and managed services to large enterprises and government agencies is hiring a senior DevSecOps engineer for its cloud security practice. The role centers on designing, automating and operating secure AWS environments for clients, with a strong focus on web application firewall deployment and infrastructure as code. The team works closely with client cloud, platform and security staff and values documentation and automation that clients can run on their own.

What you'll do

  • Design, deploy and operate secure multi-account AWS environments covering networking, identity and logging foundations
  • Build and maintain infrastructure as code (Terraform, OpenTofu or CloudFormation) with reusable modules, managed state and reviewed plans
  • Deploy, tune and migrate web application firewalls and edge protection platforms such as AWS WAF, Cloudflare or Azure WAF
  • Assess AWS configurations for IAM, network exposure, encryption and logging risk, and guide or implement remediation
  • Build CI/CD pipelines (such as GitHub Actions) that provision and validate cloud infrastructure and security controls
  • Write architecture documents, migration plans, runbooks and risk and rollback explanations for technical and non-technical audiences

What you need

  • 6+ years of hands-on experience architecting and operating AWS environments, including compute, networking, storage, identity and multi-account design
  • Hands-on experience with infrastructure as code and reusable modules, with state management at scale
  • Experience operating web application firewalls, preferably AWS WAF, including managed and custom rules, log analysis and false-positive tuning
  • Strong AWS security knowledge: least-privilege IAM, network segmentation, KMS encryption, CloudTrail and CloudWatch
  • Solid scripting skills in Python, Bash or similar, plus Git and CI/CD experience
  • Must be authorized to work in the US for any employer without sponsorship, and located in the Eastern or Central Time Zone to work 8 AM - 5 PM Eastern hours

Applicants must be based in: United States.
