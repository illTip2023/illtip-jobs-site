Technical Onboarding & Payments Support Specialist

Remote, WorldwidePermanent, full-timePosted 3 days ago

A fully remote, permanent role supporting merchants in the payments sector through API integration, sandbox testing, go-live and ongoing live processing. The work sits between merchants' developers, internal teams, gateway technology providers and payment providers, involving investigating technical issues and keeping them moving to resolution. It suits someone with payments or API support experience who enjoys methodical troubleshooting, takes ownership of problems and communicates clearly. The organisation is a payments-focused business serving merchants across Europe, the Middle East and Africa.

What you'll do

  • Guide new merchants through API integration, authentication, credentials and sandbox testing
  • Help merchants test payment flows and move to live processing
  • Connect and configure payment provider credentials
  • Diagnose whether failures originate with the merchant, gateway, provider or setup
  • Handle live issues such as transaction failures, API errors, webhook problems and routing questions
  • Gather logs, transaction IDs and request details, then escalate and track issues to closure

What you need

  • Experience in payment gateways, PSPs, acquiring or technical payments support
  • Comfortable reading API documentation and explaining it to developers
  • Understanding of REST APIs, webhooks, callbacks, sandbox versus production and common HTTP errors
  • Practical knowledge of online payment flows
  • Methodical troubleshooting, strong ownership and the ability to manage several merchants at once
  • Clear, professional English

Open to applicants anywhere in the world.
