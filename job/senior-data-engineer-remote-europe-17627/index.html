Senior Data Engineer (Remote - Europe)

Remote · Liechtenstein, Ukraine)Full-time$100,000–$140,000 per yearPosted 5 days ago

Visa sponsorship is not available. You will join a data infrastructure and analytics team that is building a platform to turn information from many external sources into reliable, current business intelligence. The role covers the full lifecycle of the platform, from architecture and ingestion through to production operations, and supports trusted data for downstream products.

What you'll do

  • Design and build a multi-source data platform that handles concurrent ingestion, event-driven processing and orchestrated batch workflows.
  • Ingest data from provider APIs, webhooks, files and web sources, managing rate limits and failure handling.
  • Orchestrate scheduled pipelines and historical backfills using tools such as Airflow, Dagster or Prefect.
  • Build event-driven processing with message queues or task queues, including retries, dead-letter queues and controlled replay.
  • Store raw payloads in Google Cloud Storage and model data with dbt across raw, standardized and curated layers.
  • Implement idempotent upserts, data contracts, validation, pipeline tests and freshness and failure monitoring.

What you need

  • At least 5 years building and operating production data platforms that integrate multiple sources, from architecture through deployment and ongoing operations.
  • Production experience with workflow orchestration, including dependencies, retries and failure recovery. Airflow experience is preferred.
  • Hands-on production experience with dbt and Google Cloud Platform.
  • Strong Python skills, including asynchronous HTTP and concurrent processing (asyncio, aiohttp or HTTPX).
  • Strong SQL and PostgreSQL skills, including data modeling, query optimization and incremental loading.
  • Right to work in, and residence in, one of the eligible European countries listed above.

Applicants must be based in: United Kingdom, Germany, France, Netherlands, Spain, Portugal, Poland, Ireland, Italy, Belgium.
